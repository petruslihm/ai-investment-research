# 설치와 실행 안내

이 안내는 두 번째 프로그램인 **AI Investment Research Assistant의 실제 리서치 실행**을 기준으로 합니다. 분석에는 Alpaca·Gemini·OpenAI API가 모두 필요합니다.

## 1. 실행 파일 열기

**[Windows 실행 파일 다운로드](https://github.com/petruslihm/ai-investment-research/releases/download/windows-launcher-v1/AI-Investment-Research.cmd)**

Windows 10/11 x64에서 다운로드한 `AI-Investment-Research.cmd`를 엽니다. Python 3.12, 필요한 패키지, 공개된 프로그램 소스를 자동으로 준비하고 브라우저를 엽니다. Python·Git·Node.js 사전 설치나 명령어 입력은 필요하지 않습니다.

첫 실행은 다운로드와 설치 때문에 몇 분 이상 걸릴 수 있습니다. 이후에는 준비된 환경을 재사용합니다. 실행 창에 현재 단계와 오류가 표시되므로 설치 중에는 창을 닫지 마세요. 회사 PC의 다운로드·실행 제한이 있으면 해당 조직의 허용 절차가 필요합니다.

웹 링크만으로 PC에 설치가 시작되지는 않습니다. 다운로드한 파일을 직접 열어야 합니다.

## 2. 필수 API 설정

처음 열리는 **설정** 화면에 아래 값을 저장합니다. 한 제공자의 키로 다른 제공자를 대신할 수 없습니다. 각 API의 사용 권한과 호출 가능한 할당량도 있어야 합니다.

| 필수 항목 | 설정 이름 | 역할 |
|---|---|---|
| Alpaca API Key | `ALPACA_API_KEY` | 미국 종목 시장 데이터 인증 |
| Alpaca Secret Key | `ALPACA_SECRET_KEY` | 위 Key와 한 쌍으로 사용 |
| Gemini API Key | `GEMINI_API_KEY` | 신규 주식 후보의 기업 근거 조사·배분 보정 |
| OpenAI API Key | `OPENAI_API_KEY` | GPT의 조사·최종 판단 검토 |

**네 값이 모두 필요합니다.** 실행기는 값이 빠져 있으면 분석을 시작하지 않고 설정 화면으로 안내합니다. 키를 입력했다는 사실만으로 인증 성공이나 잔여 할당량을 보장하지는 않습니다. **전체 연결 확인**으로 응답 상태를 확인할 수 있으며, 이 확인도 제공자 요청을 보냅니다.

기본 분석 모델은 `.env.example`과 `config.py`에 명시되어 있습니다. 해당 모델과 사용 도구에 접근할 수 있어야 합니다. 제공자별 요청에는 비용이 발생할 수 있으며, 실행기가 API 키나 이용료를 제공하지는 않습니다.

### 공시와 알림

- **SEC 공시 조회:** 설정 화면의 연락처 이메일(`SEC_CONTACT_EMAIL`)을 입력합니다. API 키는 아니며 공시 요청의 연락처로 사용됩니다. 접근이 차단되면 해당 공시의 부재·실패 상태가 남습니다.
- **카카오 알림:** 원할 때만 별도 카카오 개발자 앱을 연결합니다. 핵심 리서치의 필수 API는 아닙니다. 자동 실행기는 빈 로컬 포트를 선택하므로 실제 접속 주소에 맞는 Redirect URI를 등록해야 합니다.
- **Anthropic:** 현재 핵심 리서치의 필수 제공자가 아니며 Gemini·OpenAI 키를 대신하지 않습니다.

## 3. 실제 분석 순서

1. **설정**에서 필수 API 키를 저장하고 연결 상태를 확인합니다.
2. **포트폴리오**에서 기준 단위와 보유 상태를 입력합니다. 보유 종목은 분석 대상에 포함됩니다.
3. **대시보드**에서 스캔을 실행합니다. 시세 수집과 필요한 초기 모델 준비에 시간이 걸릴 수 있습니다.
4. **종목 추천**에서 검증·배분 제약을 적용한 결과를 확인하고, **LLM 기록**에서 조사와 판단 원문을 확인합니다.
5. **모델/학습**, **런타임**, **데이터 상태**에서 학습 기록·진행 상태·수집 문제를 확인합니다.

실행 파일을 여는 것만으로 스캔이나 유료 분석을 시작하지 않습니다. 이 실행기는 자동 일일 스캔·학습 스케줄을 시작하지 않으며 화면에서 직접 실행합니다. 주문을 전송하는 기능은 없습니다.

GPT 분석이 중단되면 저장된 입력과 재개 조건을 확인합니다. 동일 입력이면 앞서 저장한 후보·조사 결과를 사용해 이어가고, 가격·계좌·배분 기준이 달라지면 새 평가가 필요합니다.

## 4. 다시 실행·종료·저장 위치

- 다시 실행할 때에도 같은 `.cmd` 파일을 엽니다. 동일 프로그램이 실행 중이면 그 화면을 다시 엽니다.
- 실행 창에서 **Ctrl+C**를 누르면 서버를 종료합니다. 브라우저 탭만 닫으면 프로그램은 계속 실행될 수 있습니다.
- 전용 설치 폴더는 `%LOCALAPPDATA%\AIR`입니다. 시스템 Python이나 PATH를 바꾸지 않습니다.
- Python은 `python`, 패키지는 `venv`, 프로그램은 `apps\<소스 버전>` 아래에 저장됩니다.
- API 설정은 해당 프로그램 폴더의 `.env`, DB·학습 산출물은 그 폴더의 `data` 아래에 저장됩니다. 이 파일들은 GitHub에 올리지 않습니다.
- 실행 파일은 확인한 소스 버전에 고정됩니다. 다른 버전으로 교체할 때 이전 설정·데이터가 자동 이전된다고 가정하지 마세요.

## 5. 문제가 생겼을 때

| 증상 | 확인할 내용 |
|---|---|
| 설치 또는 다운로드 실패 | 인터넷 연결, 회사의 다운로드 제한, 실행 창의 오류를 확인하고 다시 실행합니다. |
| 브라우저가 열리지 않음 | 실행 창의 `App ready:` 뒤 주소를 브라우저에 입력합니다. |
| 분석 대신 설정 화면이 열림 | 필수 API Key 네 값이 모두 저장됐는지 확인합니다. |
| 키를 넣었는데 호출 실패 | 인증 상태, 모델·도구 접근 권한, 할당량, 호출 오류를 확인합니다. |
| 다른 실행이 준비 중이라는 메시지 | 먼저 열린 실행 창이 설치를 끝낼 때까지 기다립니다. |
| 포트폴리오 금액이 미확정 | 가격이나 보유 입력의 누락을 확인합니다. 미확정 금액을 0으로 바꿔 진행하지 않습니다. |

## 개발자가 직접 실행할 때

Python 3.12와 uv를 준비한 뒤 저장소 루트에서 실행합니다.

```powershell
uv sync --locked
uv run investassist --app
```

직접 실행의 기본 주소는 `http://127.0.0.1:8743`입니다. 필수 API는 동일합니다. 자동 실행기와 달리 이 기존 진입점은 앱 실행 중 일일 스캔·학습 스케줄을 활성화할 수 있습니다. 수동 평가만 하려면 자동 실행기를 사용하세요.

React/Vite는 별도 개발용 클라이언트입니다. 위 실행에는 Node.js나 React 빌드가 필요하지 않습니다. 검사 명령과 검증 범위는 [검증 기록](VALIDATION.md)에 있습니다.
