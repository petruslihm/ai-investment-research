# 검증 범위와 한계

- **연구·데모 도구:** 수익 보장이나 검증된 초과수익을 주장하지 않습니다. 실제 투자 판단과 주문은 사용자의 영역이며 주문 API는 없습니다.
- **합성 출력:** 기본 데모의 Quant/Gemini/GPT 출력은 수작업 예제입니다. 실제 모델 추천·API 응답·운영 기록을 복사하지 않았습니다. 검증·제약·저장·복원 코드만 실제 코드로 실행합니다.
- **실제 API 미검증:** 공개 제출 작업에서는 유료 API를 호출하지 않았습니다. 실제 제공자의 모델 ID·도구 지원·형식 준수·사실성·현재 비용을 보증하지 않습니다. 출처 URL 존재만으로 원문과 주장이 일치한다고 보증하지 않습니다.
- **가격·시간:** 완료 일봉만 피처와 거래량 비교에 사용합니다. 장중 관측은 별도 가격 출처로 표시합니다. 제공자가 체결 시각을 주지 않으면 수집 시각과 구분해 미제공으로 표시합니다. 시간대별 거래량 보정·새 실적 이벤트 분석은 구현하지 않았습니다.
- **불완전한 과거 재현:** 단계별 동일 입력 기록은 보존하지만 당시 universe·컨센서스·웹 원문·모든 모델 계수까지 고정하는 완전한 과거 재현 체계는 아닙니다. 현재 universe 기반 과거 분석에는 생존편향이 있으며 소표본 진단에는 in-sample 예외가 있습니다.
- **성과 측정:** 기존 outcome은 종목 가격수익률입니다. 행동·배분·현금·거래비용·회전율을 반영한 전략 성과 비교가 아닙니다. 단계 분리는 추적 가능성을 제공하며 투자 효과를 증명하지 않습니다.
- **재개:** 공개본은 현재 계약과 동일 입력 guard의 패키지만 재개합니다. 보유 의미가 상충하면 재평가 필요로 남깁니다. 과거 운영 기록 마이그레이션·백업 자동화는 포함하지 않습니다. 동일 입력 재개는 오래된 원문을 새 조사로 만드는 기능이 아닙니다.
- **로컬 단일 사용자:** 데모는 loopback에서 동작합니다. 다중 사용자·인증·HA를 갖춘 공개 서비스가 아닙니다. 실제 연구 설정에서는 입력 근거와 포트폴리오 맥락이 외부 LLM에 전달될 수 있습니다.
- **기존 React 선택 구성:** 이전 검증에서 npm 의존성 moderate/high 경고가 보고됐습니다. 이번 Python 데모에는 React/Vite가 사용되지 않으며 해당 경고를 해결했다고 주장하지 않습니다.
