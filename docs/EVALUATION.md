# 평가 결과와 근거

평가 기준은 세 가지로 나눕니다. 소프트웨어가 계약대로 동작하는지, 실제 운영에서 어떤 일이 있었는지, 투자 성과가 개선됐는지는 서로 다른 질문입니다.

## 현재 확인할 수 있는 것

| 증거 | 확인한 내용 | 확인하지 못한 것 |
|---|---|---|
| 공개 합성 데모 | 판단 변경·배분 한도·실패 대체·미확정 보유·저장 복원 | 실제 모델 또는 API의 판단 품질 |
| 공개 pytest·패키지 검사 | 코드 동작, 회귀 방지, 설치 산출물의 실행 | 실거래 수익률·상용 운영 안정성 |
| 별도 etf-radar의 과거 실행 메타데이터 | 당시 요청·토큰·상태·전체 경과 시간 | 이 공개본의 API 성능이나 일반적인 응답 시간 |
| 별도 etf-radar의 코드·테스트 확인 | 입력 완전성과 지정 판단 필드 보존 통제 | 모든 자연어 의미·외부 원문의 사실성 |
| 작성자의 개인 운용 경험 | 기존 로직을 다시 개선하게 된 동기 | 두 전략의 통계적으로 검증된 우열 |

공개본의 실제 명령과 결과는 [검증 기록](VALIDATION.md)에 있습니다. 테스트 수를 투자 성과 점수로 사용하지 않습니다.

## 별도 etf-radar 운영 사례: 1회 실행의 집계

2026-09-10에 완료된 과거 실행의 응답 메타데이터를 같은 날 다시 읽어 집계했습니다. 원본은 비공개 로컬 운영 기록이며, 이 저장소에서 독립 재현할 수 없습니다. 아래는 원문 전체의 사실 검증이나 청구서 대조 결과가 아닙니다.

| 항목 | 관찰값 | 해석 |
|---|---:|---|
| 기록된 응답 | 18회 | 중단·후속 진행을 포함한 기록 수 |
| 응답 상태 | completed 17회, incomplete 1회 | 상위 실행의 완료와 개별 응답 상태를 구분 |
| 입력 토큰 | 1,362,958 | 요청별 합계; 아래 캐시 토큰 포함 |
| 캐시 입력 토큰 | 219,374 | 입력 토큰에 별도로 더하지 않음 |
| 출력 토큰 | 137,005 | 메타데이터 기준; reasoning 포함 |
| `web_search_call` 기록 | 126개 | 고유 원문 수나 사실 검증 횟수는 아님 |
| 시작부터 종료까지 | 67분 9초 | 실패·수정·복구가 포함되어 정상 처리 지연으로 일반화할 수 없음 |

이 실행은 API로 반복 조사를 수행했다는 운영 사례입니다. 성공률이나 비용 절감을 계산하기에는 표본이 부족합니다. 실제 청구액·현재 단가를 재검증하지 않았으므로 비용 수치를 성과로 제시하지 않습니다. 개인 보유·원문 응답·운영 DB는 공개하지 않습니다.

같은 날 별도 체크아웃의 `tests/test_research_features.py`를 실행해 **6개 테스트 통과**를 확인했습니다. 이는 당시 운영 버전의 전체 회귀 검사나 공개 저장소의 테스트 개수에 합산되는 결과가 아닙니다. 구체적인 통제와 한계는 [사례 문서](CASE_STUDIES.md)에 설명합니다.

## 공개 모델 지표의 해석

현재 배치 학습의 회귀 지표는 모델별 **단일 시간순 분리 MAE**입니다. 해당 모델의 실제 평가 입력을 사용하고, 학습·평가 중복이나 예측 기간에 필요한 날짜 간격 부족이 있으면 수치를 남기지 않습니다. 작은 표본에서 학습을 계속하는 기존 동작과 성능을 입증할 수 있는지는 별개입니다.

순위 모델은 적절한 순위 평가가 아직 구현되지 않아 평가 불가로 표시합니다. 과거의 공통 `walkforward_mae` 기록은 여러 모델의 성능 증거로 사용하지 않습니다. 다른 시점에 학습한 모델끼리 서로 다른 평가 구간의 수치를 직접 비교해 개선율을 제시하지 않습니다.

이 진단은 반복 walk-forward나 전략 백테스트가 아닙니다. 현재 universe 선택, 과거 원문·모델 상태의 불완전한 보존, 실제 거래비용 반영 부족이 남아 있습니다.

## 다음에 수행할 비교 — 아직 미실행

먼저 같은 후보·계좌 snapshot·판단 시각을 고정하고, 실제 API 출력을 보존하는 전향적 실험이 필요합니다. 현재 데이터를 넣고 과거 AI 판단을 재현한 것처럼 평가하지 않습니다.

| 비교 질문 | 측정 계획 |
|---|---|
| 수동 GPT 작업이 얼마나 줄었는가 | 같은 과제의 사람 개입 횟수·소요 시간·수정 횟수 |
| 자동화가 안정적으로 완료되는가 | 최초 완료율, 재시도율, 불완전 응답률, 단계별 지연 |
| 통제가 필요한 오류를 잡는가 | 누락 계좌·판단 필드 변경·잘못된 종목·단위의 검출 및 오탐 |
| 근거를 확인할 수 있는가 | 주장과 원문의 일치율을 사람이 표본 평가; URL 존재와 구분 |
| 비용에 비해 유용한가 | 과제별 실제 사용량·청구액·캐시 비중과 사람 평가 |
| 투자 결과가 나아졌는가 | 같은 자본·기간·종목군·거래 시점·비용·현금 조건의 전향적 모의 운용 |

투자 비교에서는 수익률만 보지 않고 최대 낙폭, 변동성, 회전율, 비용, 비교지수 대비 결과를 함께 기록해야 합니다. 이 계획을 실행하기 전까지 `etf-radar`가 더 우수하다거나 LLM 단계가 초과수익을 만든다고 주장하지 않습니다.
